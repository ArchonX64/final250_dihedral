CHEM 250 Final Project: Dihedral Rotation Energy Calculator
Kyle Gilbert, Aerin Baker, Sohini Mandel

A simple calculator for dihedral angles of any molecule.
All it needs is an xyz file, the atom indexes to rotate about, the desired rotation parameters, and a calculator.
Generates a CSV of angles and energies (WIP) and a graph of these energies.

main.ipynb is the entrypoint for the program where all the necessary parameters are specified, and will generate the necessary data.
